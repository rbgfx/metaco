A small first step

Start with one example.

Install the gem, then follow the project guide for platform requirements and the full API.

Read the installation guide ↗

require "metaco"

Metaco.init
handle = Metaco.window_create(
  800, 600, "My Window",
  resizable: true, high_dpi: true
)
begin
  # rgba_bytes contains width * height RGBA pixels.
  Metaco.set_pixels(handle, rgba_bytes, 800, 600)
  Metaco.present(handle)
ensure
  Metaco.window_destroy(handle)
end
